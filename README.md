# VoterAI - Your Election Assistant

VoterAI is a modern, interactive web application designed to simplify the election process for Indian citizens. It provides essential facts, a clear timeline of the election cycle, a 4-step registration guide, and the latest news from the Lok Sabha and Rajya Sabha.

## Features

- **Interactive Voter Assistant**: Talk to "Vota", our AI-powered chatbot, to get answers to your registration and voting questions.
- **Dynamic Timeline**: Track key dates and milestones in the election cycle.
- **News Hub**: Stay updated with real-time news from official parliamentary sources.
- **Historical Context**: Learn about the legacy of voting rights and the constitutional foundation of Indian democracy.
- **Responsive Design**: Fully optimized for both desktop and mobile devices.

## Technologies Used

- **HTML5**: Semantic structure.
- **Vanilla CSS3**: Premium styling with glassmorphism and animations.
- **JavaScript (ES6)**: Dynamic interactivity and chatbot logic.
